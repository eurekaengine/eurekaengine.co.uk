Real attacks don’t arrive one protocol at a time.

What’s inside

A full pen-testing toolkit in a compact device.

All underpinned by a new but familiar turbo-charged scripting language, letting you write reliable scripts that react in real time.

01

BadUSB

Emulates multiple device types. Appear as a keyboard, a mouse, a storage drive or a network adapter, depending on the scenario.

02

WiFi toolkit (2.4GHz)

Contains a full range of wireless audit, survey, deauthentication and packet capture attacks.

03

Rogue access point

Quickly stand up WiFi access points to assess wireless security controls, user awareness, and device behaviour in realistic environments.

04

Bluetooth LE toolkit

New BTLE capabilities, keyboard and mouse emulation over Bluetooth, and tracking the device via Apple's Find My network.

05

Powerful host agent

Gather system info, grab credentials or files via the included cross-platform host agent. Bridge isolated segments by proxying traffic from the device back to your host network.

06

Remote screen and audio

View the target screen and stream audio over WiFi during an engagement.

07

Brand new hardware

Built-in mic and IR let you capture audio and interact with IR-controlled hardware.

Cross platform

Works across the major operating systems you meet in the field, with 100% passive OS detection and agent support for Linux and Mac.

New, fast multi-lingual web interface

Questions

Before you back it.

Who is it for?

Built for security professionals, red teams, penetration testers, and anyone who administrates systems and needs multiple different tools in their pocket at one time to do their job. Anyone from enthusiast to systems engineer to penetration tester. It packs tools from USB mouse and keyboard emulation to RF survey and attacks to complex agent-based capabilities.

How has this evolved from V1?

UAK Pro builds on two years of active development on our open-source V1 (github.com/i-am-shodan/USBArmyKnife). Pro moves to faster, more capable hardware and adds a new, smaller, multilingual web interface with a built-in screen viewer, a DuckyScript-compatible scripting engine with added string and return-code support, and a cross-platform agent for Windows, Linux and macOS. Everything you already know from V1 carries over, with far more headroom to grow.

Which operating systems does it work with?

Multi operating system support, with 100% passive OS detection and agent support for Linux & Mac.

Am I allowed to use it?

Only on systems and networks you own or have explicit written permission to test. Laws on security tools vary by country, so check yours before ordering.

When will it ship, and where to?

USB Army Knife PRO is still in the development phase. Once the Kickstarter campaign is up and running, we'll update this page with shipping information and expected delivery dates.

What are the full specs?

Prototype currently in testing — we'll update with full specification information very soon.
